# Debt Angel

**Pay someone's debt. Climb the leaderboard.**

A concept platform where high-net-worth individuals compete to pay off real people's medical bills, student loans, and consumer debt. Public scoreboard. Real impact.

## Live Site

Once GitHub Pages is enabled:
**https://richt357.github.io/debt-angel/**

## How to enable the live website (takes 1 minute)

1. Go to: https://github.com/Richt357/debt-angel/settings/pages
2. Under **Source**, select **Deploy from a branch**
3. Branch: `main`
4. Folder: `/ (root)`
5. Click **Save**

Wait 30–60 seconds, then visit:
https://richt357.github.io/debt-angel/

That's it. Your site is live.
